# Max Alexander — personal site

Personal website and online business card for Max Alexander, Business (AI) student at Arizona State University.

Live at **https://turbo121.github.io**

## Run locally

```bash
npm install
npm run dev
```

The site lives in `src/pages/index.astro`. The downloadable résumé is `public/Maxwell_Alexander_Resume.pdf`.

## Deploy

Every push to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
